The problem

what the solver on this page is optimising

Optimal control problem

minu[⋅] ℓf (x[N]) + ∑ n=0 N−1 ℓ( x[n], u[n]) subject to   x[n+1] = f(x[n], u[n]) , x[0]= x0

State and control

x= [ x y θ v δ ] ∈ ℝ5 , u= [ u0 u1 ] ∈ ℝ2
  • x, y — position (m)
  • θ — heading (rad)
  • v — speed (m/s)
  • δ — steering angle (rad)
  • u0 — acceleration (m/s²)
  • u1 — steering velocity (rad/s)

Nonlinear dynamics

Continuous time — a kinematic bicycle model, nonlinear in θ, v and δ:

x˙ = fc (x,u) = [ vcosθ vsinθ vtanδ u0 u1 ]

Discretised with a forward Euler step, which is the f the solver actually uses:

x[n+1] = f(x,u) = x+ Δt ⋅ fc (x,u)

Stage cost

ℓ(x,u) = ( x2+ y2+ ε −r ) 2 + (v− v★) 2 + w ( u02 + u12 )
  • 1 distance from the circle of radius r, squared
  • 2 deviation from the target speed, squared
  • 3 control effort, weighted by w

Final cost

The same, without the control term — there is no u[N]:

ℓf (x) = ( x2+ y2+ ε −r ) 2 + (v− v★) 2

Parameters in this run

ε smooths the square root: the derivative of √s is undefined at s = 0, which is exactly the origin of the circle cost.
